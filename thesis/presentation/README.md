# ساخت اسلایدهای دفاع

اسلایدها از قالبی ساخته می‌شوند که دانشکده داده است، و سه گام روی آن اجرا
می‌شود. ترتیب گام‌ها مهم است: کارِ ساختاری پیش از کارِ محتوایی می‌آید، چون
`add_slide.py` اسلاید را عیناً کپی می‌کند.

```bash
python3 -c "import zipfile; zipfile.ZipFile('defense_template.pptx').extractall('unpacked')"

# ۱. سه اسلاید تکرارشونده ساخته و ترتیب هفده اسلاید تنظیم می‌شود
#    (اسلایدهای ۴، ۸ و ۱۲ قالب هر کدام یک بار تکثیر می‌شوند)

python3 fill.py      # ۲. متن فارسی، راست‌به‌چپ کردن پاراگراف‌ها، فونت IRNazanin و IRTitr
python3 mirror.py    # ۳. قرینه کردن هندسه اسلایدها حول محور عمودی
python3 polish.py    # ۴. عنوان کامل، ارقام نمودار، و یادداشت گوینده با زمان‌بندی

(cd unpacked && zip -Xrq ../Antibiogram_Defense_Haddadha.pptx .)
```

قالب برای انگلیسی و چپ‌به‌راست چیده شده بود. `mirror.py` مختصات افقی هر شکل
را حول محور عمودی صفحه برمی‌گرداند، یعنی `x' = 12192000 − (x + cx)`. قرینه
کردن، فاصله هر شکل از حاشیه مقابل را حفظ می‌کند، پس دایره‌های شماره‌دار به
سمت راست متن خود می‌روند، چهار مرحله روش از راست به چپ خوانده می‌شوند، و ستون
خط پایه پیش از ستون روش پیشنهادی قرار می‌گیرد. پیکان‌های میان مرحله‌ها نیز
با `flipH` برمی‌گردند.

فونت‌ها از خودِ فایل قالب پایان‌نامه بیرون کشیده شده‌اند: Cambria قالب به
IRTitr و Calibri آن به IRNazanin نگاشت می‌شود، و همین نگاشت در `theme1.xml`
هم اعمال می‌گردد تا اجراهای ارث‌بر هم درست شوند.
