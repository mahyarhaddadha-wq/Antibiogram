# نقشه نگارش پایان‌نامه و راهنمای بازتولید

## وضعیت

همه فصل‌ها نوشته و با اعداد ارزیابی روز هماهنگ شده‌اند. نسخه Word با اجرای یک فرمان از روی همین فایل‌های Markdown ساخته می‌شود.

| فایل | محتوا |
|---|---|
| `front_matter.md` | تعهدنامه، سپاسگزاری، چکیده فارسی و انگلیسی، فهرست شکل‌ها و جدول‌ها، واژه‌نامه |
| `chapter_01.md` | مقدمه، هدف، نوآوری‌ها، محدوده |
| `chapter_02.md` | مبانی نظری، استاندارد مرجع، ابزارهای پردازش تصویر، مرور کارهای پیشین |
| `chapter_03.md` | روش پیشنهادی، چهار مرحله، راه‌های آزموده و کنار گذاشته‌شده |
| `chapter_04.md` | پیاده‌سازی، گالری خروجی گام‌به‌گام، جدول پارامترها |
| `chapter_05.md` | مجموعه مرجع، پروتکل سنجش، نتایج، تحلیل تک‌تک خطاها، نتیجه بالینی |
| `chapter_06.md` | بحث، علت ریشه‌ای، محدودیت‌ها، پیشنهاد مدل‌سازی ریاضی، کار آینده |
| `references.md` | ۱۸ منبع به سبک IEEE، به ترتیب نخستین ظهور در متن |
| `appendix_a_evaluation_data.md` | هر ۹۳ سطر خروجی ارزیابی |

## ساخت نسخه Word

```
npm install docx adm-zip          # یک‌بار
python3 thesis/make_figures.py        # نمودارها
python3 thesis/make_figures_extra.py  # مقایسه کیفی با خوانش کارشناس
python3 thesis/make_pipeline_gallery.py gt_02 gt_06 gt_10   # گالری گام‌به‌گام
node thesis/build_docx.js
```

خروجی: `thesis/Antibiogram_Thesis_Haddadha.docx`

## قواعد نگارشی که رعایت شده‌اند

- بدون کسره اضافه و بدون خط تیره بلند در متن فارسی
- هر جمله خبری با فعل پایان می‌یابد، به جز عنوان‌ها و فهرست‌های پس از دونقطه
- بدون جمله پرسشی و بدون علامت تعجب
- ارجاع به مرحله‌ها با نام کاری، نه با شماره درونی؛ نگاشت نام به سلول در جدول ۴-۱
- شماره ارجاع و شماره پانویس با رقم فارسی، متن پانویس و متن منبع به انگلیسی
- متن نمودارها به انگلیسی و با قلم هم‌متریک Times New Roman

اجرای `python3 thesis/check_style.py` این قواعد را می‌سنجد.

## قلم نمودارها

قلم Times New Roman پروانه انتشار مجدد ندارد، پس نمودارها با Tinos ساخته شده‌اند که هم‌متریک و هم‌شکل آن است. اگر روی ویندوز یا رایانه‌ای که Office دارد `make_figures.py` دوباره اجرا شود، خود Times New Roman به کار می‌رود و اسکریپت به طور خودکار آن را انتخاب می‌کند.
