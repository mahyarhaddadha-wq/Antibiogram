# پوشه‌ی پایان‌نامه

این پوشه محلِ نگهداریِ فایل‌های مربوط به نگارشِ پایان‌نامه است (تمپلیتِ دانشگاه، پروپوزال، پیش‌نویس‌ها، و مشابه آن) — جدا از کدِ پروژه و مستنداتِ فنی (`PROJECT_HISTORY.md`, `EVALUATION.md`).

هر فایلی که لازم دارید (Word، PDF، ...) را همین‌جا اضافه کنید؛ وقتی آماده بود، با هم رویِ نگارشِ خودِ پایان‌نامه کار می‌کنیم.
