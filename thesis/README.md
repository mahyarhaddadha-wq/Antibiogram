# پوشه‌ی پایان‌نامه

این پوشه محلِ نگهداریِ فایل‌های مربوط به نگارشِ پایان‌نامه است — جدا از کدِ پروژه و مستنداتِ فنی (`PROJECT_HISTORY.md`, `EVALUATION.md`).

## فایل‌های موجود

| فایل | توضیح |
|---|---|
| `proposal.pdf` | فرمِ پیشنهادِ پروژه‌یِ کارشناسیِ تصویب‌شده |
| `thesis_template.docx` | قالبِ رسمیِ پایان‌نامه‌یِ دانشگاه اصفهان |

## اطلاعاتِ پروژه (برگرفته از پروپوزال)

- **گروه:** مهندسی پزشکی — دانشگاه اصفهان
- **دانشجو:** مهیار حدادها (شماره‌ی دانشجویی ۴۰۱۲۰۱۳۰۵۳)
- **استاد راهنما:** دکتر محمدرضا یزدچی
- **نوعِ پروژه:** کامپیوتری — پردازش/مدل‌سازی/شبیه‌سازی + بسته‌ی نرم‌افزاری

**عنوانِ فارسی:**
> طراحی و پیاده‌سازی سامانه هوشمند تحلیل خودکار آزمون آنتی‌بیوگرام مبتنی بر پردازش تصویر و یادگیری ماشین مطابق استاندارد EUCAST

**عنوانِ انگلیسی:**
> Design and Implementation of an Intelligent Automated Antibiogram Analysis System Based on Image Processing and Machine Learning According to EUCAST Standards

## نکاتی که هنگامِ نگارش باید به آن‌ها رسیدگی شود

دو موردِ زیر تفاوتِ میانِ آن‌چه پروپوزال وعده داده و آن‌چه تا امروز پیاده‌سازی شده است — هردو باید یا در کد تکمیل شوند، یا در متنِ پایان‌نامه به‌صراحت و با استدلالِ فنی توضیح داده شوند:

1. **«یادگیری ماشین» در عنوان، اما پیاده‌سازیِ فعلی کاملاً قطعی (deterministic) و مبتنی بر بینایی ماشینِ کلاسیک است** (Hough، Blob Analysis، Watershed، پروفایلِ شعاعی) و هیچ مدلِ یادگیرنده‌ای ندارد. این خودش یک انتخابِ آگاهانه‌یِ طراحی بوده (قابلیتِ بازتولیدِ کامل، شفافیتِ الگوریتمی، و امکانِ انتقال به C++ برای سیستمِ نهفته) و در `PROJECT_HISTORY.md` مستند است — ولی باید در پایان‌نامه صریح بیان و توجیه شود، نه این‌که ناگفته بماند.

2. **«مطابق استاندارد EUCAST» در عنوان، اما طبقه‌بندیِ S/I/R هنوز پیاده‌سازی نشده.** سامانه در حالِ حاضر قطرِ هاله را بر حسبِ میلی‌متر گزارش می‌دهد، ولی گامِ نهایی (تبدیلِ قطر به «حساس/نیمه‌حساس/مقاوم» طبقِ جدول‌هایِ EUCAST) هنوز اضافه نشده. این گام برای پاسخ‌دادن به این پرسشِ داور لازم است: «خطای ۵.۵ میلی‌متری چند درصد از تصمیم‌هایِ بالینی را تغییر می‌دهد؟»

**نکته‌ی جانبی:** قالبِ ارسال‌شده متنِ «پایان‌نامه‌ی کارشناسی ارشد» دارد، درحالی‌که پروپوزال برایِ مقطعِ کارشناسی است — بهتر است پیش از شروعِ نگارش، از گروه تایید بگیرید که همین قالب برای کارشناسی هم استفاده می‌شود یا نسخه‌ی جداگانه‌ای دارد.
